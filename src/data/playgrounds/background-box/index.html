padding-box vs border-box

Every background layer can say where it stops painting. That one keyword is what makes gradient borders work.

Where each box ends

Same gradient, same 18px dashed border and 18px padding. Only background-clip changes.

The gradient border button

Two layers: the fill clipped to padding-box, the edge gradient painted across the whole border-box. The border itself is transparent, so the lower layer shows through exactly there — and nowhere else.

fill padding-box + edge border-box

both layers border-box — the fill covers the edge

no transparent border — the edge has nowhere to show

layers swapped — the edge paints over the fill
