1. 漸層描邊：雙 background 分層

底色漸層只畫在 padding-box，描邊漸層畫在 border-box，border 本身 transparent。

background: <填色> padding-box, <描邊> border-box;

2. 同上，但填色終點寫 130%

終點落在按鈕下緣之外，底部只到約 #2D343A，整顆偏暗、描邊對比變小。

#20272D 0% → #343B41 130%

3. 半透明實色描邊 + padding-box

漸層只畫到 padding 邊緣，那圈 5% 白是疊在「後面的底色」上。

background-clip: padding-box;

4. 同上，但少了 padding-box

預設 border-box：漸層延伸到 border 底下，5% 白疊在自己的漸層上，描邊幾乎消失。

background-clip: border-box; /* 預設 */
