Gradient Borders

Same goal, four techniques. The backdrop is busy on purpose: it shows which ones keep the inside transparent.

border-image

One declaration on top of a normal border.

  • Shortest to write
  • Ignores border-radius

background-clip

A solid layer on padding-box over a gradient on border-box.

  • Rounded corners
  • Inside needs a solid fill

mask-composite

A pseudo-element masked down to just the border ring.

  • Rounded and truly transparent
  • Uses up a pseudo-element

Rotating glow

@property registers the angle so the conic-gradient can spin.

  • Animated, still transparent
  • Needs @property support
